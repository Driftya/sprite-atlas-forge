# Sprite Atlas Forge v1.0.3

Maintenance release improving connector editing responsiveness, selection clarity, and Windows distribution size.

## Highlights

- Connector border nudging now batches rapid arrow-key presses and commits the final geometry once nudging pauses, keeping the canvas responsive during repeated edits.
- Selecting a sprite border clears connector selection so keyboard commands act on the active editing mode.
- Border selection changes are coordinated between the canvas and page model, including explicit clearing when selecting or reselecting connectors.
- Connector points now use a smaller center marker with a clearer selected outline, and the connector name tooltip is positioned and sized more compactly.
- Windows releases now use framework-dependent publishing instead of bundling the .NET and Windows App SDK runtimes.
- Release publishing omits debug symbols, reducing the validated archive from approximately 96 MB to approximately 27 MB.
- Updated the example `ship-modules-01.saf.json` project data to match the current native project representation.

## Installation requirement

The Windows desktop release requires the .NET 10 Desktop Runtime (x64) and Windows App Runtime 1.8 to be installed separately. Windows 10 version 1809 or newer remains supported.
