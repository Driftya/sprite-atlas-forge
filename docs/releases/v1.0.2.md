# Sprite Atlas Forge v1.0.2

Maintenance release improving connector selection, keyboard nudging, and editor clarity in the Windows desktop application.

## Highlights

- Clicking a connector now selects it clearly, and clicking the same connector again deselects it.
- Selected connector points show a visible outline for easy identification.
- Arrow-key nudging now works for the selected connector without blocking sprite border resizing.
- Escape clears the active connector or border selection for faster keyboard editing.
- Selected connector names appear as a compact tooltip so the canvas stays clean.
- Added regression coverage for connector selection and nudge behavior.
