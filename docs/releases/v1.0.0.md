# Sprite Atlas Forge v1.0.0

Initial production release of Sprite Atlas Forge for Windows.

## Highlights

- Detect sprites in transparent or border-connected PNG spritesheets.
- Edit sprite regions, connector metadata, tags, and approval state in the desktop editor.
- Repack atlases deterministically without rotation.
- Export Phaser JSON Hash, Unity 6 multi-sprite, and Godot 4 `AtlasTexture` formats.
- Save native `.saf.json` projects with dirty-state protection and undo/redo.
