# Sprite Atlas Forge v1.0.1

Maintenance release improving generated-art detection and keyboard editing in the Windows desktop application.

## Highlights

- Added opt-in recovery for faint and detached details excluded by Auto detection's primary alpha cutoff.
- Added undoable recovery for an individual selected sprite.
- Added `--recover-detached-details` for CLI detection workflows.
- Improved recovery ownership so nearby pixels are assigned to the nearest unambiguous sprite.
- Added Left/Right navigation between sprites when no resize border is selected.
- Kept Delete-key removal available while hiding the transient Windows accelerator hint that appeared over the canvas.
- Added regression coverage using the bundled ship-module image fixtures.
