Especially MergeDistance, because your generated ship modules may contain disconnected pieces that visually belong to one sprite.

The desktop detection panel keeps a visible label and unit beside every cleanup option. Merge distance must be described as a transitive pixel-gap grouping control: values much larger than the default can join neighboring modules until the whole sheet becomes one region. At normal distances grouping measures the separation between component pixels rather than bounding rectangles; containment remains a separate rule for details inside transparent holes. Automatic background mode starts with a broad, detail-preserving histogram split and only tests stronger alpha cutoffs when the resulting mask contains an anomalous sheet-scale component. It chooses the last major connectivity collapse below the dominant foreground-alpha band. A second seeded magic-wand pass grows higher-alpha markers into nearby soft-alpha silhouette pixels for a bounded distance. Marker count alone is not split evidence: a split also requires a low-density vertical gutter across the coarse region and substantial confident content on both sides. This conservative XY-cut signal keeps internal highlights and vertically stacked details together while separating row-arranged sprites connected by residue.

The Windows-first MAUI editor and CLI share Application rules for sprite-region correction and named connector creation, movement, rename, and deletion. Connector coordinates remain sprite-local integers and are preserved by native save/load and untrimmed repacking. The MAUI canvas supports direct sprite selection, Delete-key removal outside text editing, eight-handle source-region resizing with magnetic original/image/sprite-edge snapping and alignment guides, right-mouse drag panning, right-button pointer-centered wheel zoom, connector click placement, and connector drag movement at any zoom level, while exact numeric inputs remain the accessible fallback. The properties panel can save the selected displayed frame as a lossless PNG crop. All sprite bounds are drawn in one overlay surface, so zoom changes update the canvas transform instead of rebuilding hundreds of border and label controls. Editor changes are tracked as dirty, support undo/redo, and prompt before being discarded.

Generated spritesheets support both transparent and fully opaque backgrounds. Automatic detection derives an alpha cutoff from the image histogram so colored low-alpha generation noise does not bridge otherwise separate sprites. On noisy transparent sheets it follows coarse component detection with bounded, seeded region growing: a softer support mask restores nearby antialiased edges, while blue-dominant engine glow uses a larger bounded recovery radius so low-alpha flare tails are retained without absorbing neutral shadows. Layout-aware gutter validation permits marker splits only between substantial horizontally separated regions. When the sheet is fully opaque, Auto instead removes the smoothly varying background connected to the image border. A configurable mask opening removes isolated generation noise and thin bridges without filling transparent holes. Component bounds that overlap or contain one another are otherwise grouped so a disconnected opaque detail inside a transparent window does not become a second sprite. A below-minimum fragment may attach to one nearby qualifying component, preserving details such as a small engine plume; automatic mode allows a wider eight-pixel attachment search for these isolated edge details, while an ambiguous fragment is discarded rather than bridging two sprites. Raw pixel-art behavior remains available with alpha-only background mode, minimum area 1, merge distance 0, and noise-reduction radius 0. The editor permits users to add a manual sprite region or delete the selected region, with both actions tracked by undo/redo. Clicking a straight edge of a selected region highlights that border red; left/right nudge vertical borders and up/down nudge horizontal borders by one source pixel, clamped to the image and a one-pixel minimum region.
